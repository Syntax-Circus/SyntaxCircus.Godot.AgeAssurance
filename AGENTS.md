# Age assurance library

Use feature branches in this checkout, never worktrees. Keep addon contracts free of app-specific paths, legal text, save formats and minimum ages. Initialize native APIs only on explicit checks. Never log/store/send bounds or platform install identifiers. Distinguish age eligibility, mandatory verification, pending/declined approval and regulatory obligations. Run tests with Godot 4.7.2 headless; build Android against SDK 36/JDK 17; iOS needs a Mac with an iOS 26.4+ SDK and matching Godot headers.
